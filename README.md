# DO 融合工作台 V2.0

**进度管理 · 专项任务 · 头脑风暴**

在线使用：**https://rocstarliu-crypto.github.io/do/**

本仓库发布正确的 DO 融合工作台 V2.0 单文件版本，冻结基线为：

- 进度管理 V1.11
- 专项任务 V1.4.1
- 头脑风暴流程画布 V1.13

## 三大模块

1. **进度管理**：我的一天、计划内、全部任务、日程、四状态、工作日志、分类、子任务、回收站、撤销/重做、Excel。
2. **专项任务**：多项目标签、四级任务树、动态列、筛选、状态/进度、状态图、Excel、保存/打开、历史版本。
3. **头脑风暴**：节点与层级、LR/TB布局、连接线、配平、上下游审查与建议、模板、项目保存、Excel和多格式导出。

## V2.0 本次更新

- 删除“开发档案”页面入口，需求与验收证据改由独立验收表和 Git 历史保存。
- 主进度模块的“任务状态”保持四个业务状态；历史归档作为“已完成”的子集简要展示。
- 删除专项任务顶部的版本说明和本地验收范围说明。
- 专项任务工作区改为全宽、最小 900px 高，任务增多后继续在内部滚动查看。
- 批注工具新增“提交反馈”：自动汇总批注并下载 TXT，可预填邮件或 GitHub Issue；最终发送/提交由用户确认。
- 修复左下角/顶部统一账号入口：恢复 V1.11 稳定加载回退，并迁入 V1.4.1 的邮箱注册、确认邮件、登录、忘记密码、设置新密码和会话保持流程。
- 头脑风暴模块删除通用顶部整行和浏览器保存提示，改用通俗功能说明，并扩大画布可用高度。
- “已完成→完成待优化”的点击推进存在历史记录冲突，本次只输出对话追溯并标识冲突，未擅自改动生命周期代码。
- 专项任务 V1.4.1 和画布 V1.13 的内嵌原始负载保持不变。
