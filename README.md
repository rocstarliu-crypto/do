# DO · 进度管理 V1.5

**任务 · 工作日志 · 专项任务**

在线使用：**https://rocstarliu-crypto.github.io/do/**

这是由两套既有网页能力融合形成的统一工作台：

1. **Idea Task Hub / 任务与工作日志**：我的一天、全部任务、日程、四状态、完成工作归档、分类、回收站、撤销恢复、Excel 等。
2. **project-progress-manager / 专项任务**：四级任务树、多项目标签、自定义列、状态/进度、Excel、Supabase 注册登录、共享协作、历史版本、登录历史等。

“头脑风暴”继续保留独立模块入口，后续按流程画布需求继续完善。

## V1.5 品牌

默认左上角采用三层表达：

- **DO**：品牌标志与简称；
- **进度管理**：产品主名称；
- **任务 · 工作日志 · 专项任务**：三项核心能力。

用户可以在左上角品牌区域点击设置按钮（或双击品牌区域），自定义：标志文字、简称、主名称和副标题。品牌设置保存在浏览器本地，并写入全站 Excel 的“设置”工作表。

## 主要模块

- **我的一天**：当天任务；快速添加默认当天。
- **全部任务**：参照 Microsoft To Do 按今天、明天、日期段、稍后分组，支持折叠和数量显示。
- **日程**：日 / 周 / 月查看任务与子任务。
- **四状态**：仅展示今天和明天，未开展 → 进行中 → 已完成 → 完成待优化；单击推进，双击编辑。
- **工作日志**：只归档“哪一天完成了什么”，近期按日、历史按月折叠，可人工编辑/删除。
- **专项任务**：完整融合 project-progress-manager V1.4.1 的项目进度管理功能。
- **头脑风暴**：入口保留，后续继续完善流程画布。

## 专项任务公开版数据规则

公开站中的“专项任务”使用独立副本和独立浏览器存储：

- 首次打开只保留一个空白“项目一”；
- 不包含原 project-progress-manager 的示例项目和示例任务；
- 不读取原 project-progress-manager 页面在浏览器中保存的旧任务；
- 原 project-progress-manager 独立网站不受影响。

## 账号与云端

最外层“登录云端”沿用 project-progress-manager 的 Supabase Auth：邮箱注册、确认邮件、登录、忘记密码。专项任务继续使用同一账号体系和 RLS 数据权限。

## Excel

- 最外层全站 Excel：任务、分类、完成日志、活动记录、设置，以及专项任务工作簿/任务数据。
- 专项任务内部仍保留单独 Excel 导入/导出。

## 本地使用

本地单文件名称：`Idea_Task_Hub_V1.5.html`。

直接双击即可使用普通任务、日程、四状态和工作日志；专项任务及云端功能需要网络。

## 发布

GitHub Pages 由 `.github/workflows/pages.yml` 自动构建。构建过程中会：

1. 基于完整 V1.4 主程序生成 V1.5；
2. 应用 DO 品牌及自定义设置；
3. 把 project-progress-manager 复制到 `/special/`；
4. 清空专项任务默认示例数据并使用独立存储；
5. 发布为 `https://rocstarliu-crypto.github.io/do/`。
