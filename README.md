# Idea Task Hub V1.4｜进度管理

一个面向个人任务、工作日志与专项项目管理的轻量网页工具。

在线版本计划发布在：

**https://rocstarliu-crypto.github.io/do/**

## V1.4 当前模块

- **我的一天**：集中查看当天需要处理的任务。
- **全部任务**：参照 Microsoft To Do 的计划内视图，按今天、明天、近期日期和稍后分组。
- **日程**：按日 / 周 / 月查看任务和子任务。
- **四状态**：只显示今天和明天的任务，按“未开展 / 进行中 / 已完成 / 完成待优化”查看和推进。
- **工作日志**：只归档“哪一天完成了什么工作”，历史按日期和月份查看。
- **专项任务**：完整接入原 `project-progress-manager` 项目管理模块，包括四级任务树、多项目标签、Excel、云端协作与历史版本等功能。
- **头脑风暴**：入口已预留，后续继续完善。

## 首次打开的数据规则

公开版**不内置任何个人任务、个人日志或个人专项任务数据**。

首次打开时：

- 任务列表为空；
- 工作日志为空；
- 回收站为空；
- 仅保留“计划 / 工作 / 学习 / 长期计划 / 生活”等通用分类，方便直接开始使用；
- 浏览器数据保存在当前设备本地，不会随着公开仓库一起发布。

公共版使用独立的浏览器存储键，不会主动读取此前其他 Idea Task Hub 页面保存的个人任务。

## 账号注册 / 登录

页面顶部提供“登录云端”。账号体系沿用现有 `project-progress-manager` 的 Supabase Auth：

1. 点击“登录云端”；
2. 填写邮箱和至少 6 位密码；
3. 点击“注册账号”；
4. 按确认邮件完成邮箱验证；
5. 返回网页登录。

专项任务模块与原项目进度管理使用同一套账号体系。用户数据权限由 Supabase Row Level Security 控制，公开 GitHub 仓库不会包含用户密码或用户云端数据。

## Excel

### 进度管理全站 Excel

最外层支持全站 Excel 导入 / 导出，涵盖：

- 主任务与子任务；
- 分类；
- 日期、状态、周期设置；
- 工作日志数据；
- 专项任务工作簿快照（在同域 GitHub Pages 环境打开专项任务后可纳入总备份）。

### 专项任务 Excel

专项任务模块仍保留自己独立的 Excel 导入 / 导出功能，便于只处理当前专项项目。

## 本地使用

下载 `Idea_Task_Hub_V1.4.html` 后直接双击即可打开。

本地使用时，普通任务功能无需服务器；专项任务、账号注册/登录和云端协作需要联网。

## GitHub Pages 发布

仓库已经包含 `.github/workflows/pages.yml`。仓库设为 **Public** 后，推送到 `main` 会自动尝试部署 GitHub Pages。

如果 Pages 尚未启用：

1. 打开仓库 `Settings`；
2. 进入 `Pages`；
3. Source 选择 **GitHub Actions**；
4. 重新运行 `Deploy GitHub Pages` 工作流。

## 数据与隐私

- GitHub Pages 只托管静态网页代码；
- 未登录状态下，普通任务主要保存在浏览器本地；
- 云端账号和专项协作使用 Supabase；
- 前端只使用 Supabase 官方允许公开的 publishable key，不包含 `service_role` 私密密钥；
- 公开仓库不应上传个人任务 Excel、浏览器导出的私人工作簿或其他敏感资料。
